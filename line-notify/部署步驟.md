# LINE 通知部署步驟

## 前置準備：取得 LINE Bot 資訊

1. 前往 [LINE Developers Console](https://developers.line.biz/)
2. 登入 → 選擇或建立 Provider
3. 建立 **Messaging API** Channel
4. 進入 Channel → **Messaging API** 頁籤
5. 拉到最下方 → **Channel access token** → 點「Issue」取得 Token
6. 回到 **Basic settings** 頁籤 → 找到 **Your user ID**（格式：`Uxxxxxxxxx`）
7. 用 LINE 掃描頁面上的 QR Code，**將 Bot 加為好友**（必要步驟，否則 Bot 無法傳訊息給你）

---

## Step 1：部署 Edge Function

### 方法 A：使用 Supabase Dashboard（不需安裝 CLI）

1. 前往 [Supabase Dashboard](https://supabase.com/dashboard) → 選擇你的專案
2. 左側選單 → **Edge Functions** → 點「+ New Function」
3. Function 名稱填：`line-notify`
4. 將 `supabase/functions/line-notify/index.ts` 的內容貼入編輯器
5. 點「Deploy」

### 方法 B：使用 Supabase CLI

```bash
# 安裝 CLI（若尚未安裝）
npm install -g supabase

# 登入
supabase login

# 部署（--no-verify-jwt 讓 pg_cron 可以用自訂 CRON_SECRET 呼叫）
supabase functions deploy line-notify \
  --project-ref legwqtrutzpbwqumvvkb \
  --no-verify-jwt
```

---

## Step 2：設定 Secrets（環境變數）

前往 Supabase Dashboard → **Project Settings** → **Edge Functions** → **Secrets**

新增以下四個 Secret：

| 名稱 | 值 |
|------|-----|
| `LINE_CHANNEL_TOKEN` | 你的 LINE Channel Access Token |
| `LINE_USER_ID` | 你的 LINE User ID（格式 `Uxxxxxxxxx`） |
| `CRON_SECRET` | 自訂一串隨機密鑰，例如 `mySecret2025!` |

> `SUPABASE_URL` 和 `SUPABASE_SERVICE_ROLE_KEY` 系統會自動注入，不需手動新增。

---

## Step 3：手動測試 Function

在 Edge Functions 頁面，選擇 `line-notify` → 點「Test」，
或直接用 curl 測試：

```bash
curl -X POST \
  https://legwqtrutzpbwqumvvkb.supabase.co/functions/v1/line-notify \
  -H "Authorization: Bearer 【你的 CRON_SECRET】" \
  -H "Content-Type: application/json" \
  -d '{}'
```

預期回應（有待辦時）：
```json
{
  "success": true,
  "date": "2025-06-12",
  "depCount": 2,
  "tickCount": 1
}
```

預期回應（無待辦時）：
```json
{
  "message": "今日無待辦事項，未發送通知"
}
```

---

## Step 4：設定 pg_cron 自動排程

1. 前往 Supabase Dashboard → **SQL Editor**
2. 開啟 `setup-cron.sql`
3. **先將第 18 行的 `【替換成你的 CRON_SECRET】` 換成你的 CRON_SECRET**
4. 執行整個 SQL 檔案

## 安全提醒

- 完成設定後，請到 LINE Developers Console **重新發行 Channel Access Token**（因為原 Token 已公開）
- `CRON_SECRET` 請使用不易猜測的隨機字串
- `setup-cron.sql` 裡的 CRON_SECRET 填入後，不要將檔案上傳至公開 Git 儲存庫

## 常見問題

**Q：測試時收不到 LINE 訊息？**
- 確認已將 Bot 加為好友
- 確認 LINE_USER_ID 格式正確（以 `U` 開頭的 33 位字串）
- 在 LINE Developers Console 確認 Messaging API 已啟用

**Q：pg_cron 沒有執行？**
- 在 SQL Editor 執行：`SELECT * FROM cron.job_run_details ORDER BY start_time DESC LIMIT 10;`
- 查看是否有錯誤訊息

**Q：想改通知時間？**
- 時間格式為 UTC，台灣時間 = UTC + 8
- 例如改為早上 8:30 台灣時間 → UTC 00:30 → cron 表達式：`30 0 * * *`
